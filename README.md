# 研究室の MS-1〜MS-4 を Claude Code から使えるようにする

研究室の共有の Windows 機 **MS-1〜MS-4** に入っている **Lumerical**(FDTD・RCWA など)・**Zemax OpticStudio**・**COMSOL**・**RSoft**(BeamPROP・FullWAVE・DiffractMOD など)を、あなたのパソコンの **Claude Code** から、あなたのアカウントで動かせるようにするための準備一式です。準備が済めば、Claude に「この計算を MS-3 で回して」と頼むだけで、計算を送る・終わるのを待つ・結果を取ってくる、までを Claude がやります。MS-1〜MS-4 の画面を開いて操作する必要はありません。COMSOL は画面で作ったモデル(`.mph`)を、RSoft は設計ファイル(`.ind`)を渡せば、Claude が送って解かせ、結果を取ってきます。

| 機 | 入っているソフト(2026-10 時点) |
|---|---|
| MS-1 | Lumerical、COMSOL 6.2 |
| MS-2 | RSoft、COMSOL 5.6 |
| MS-3 | Lumerical、COMSOL 5.6 |
| MS-4 | Lumerical、Zemax OpticStudio |

どの機に何があるかは、準備のときに Claude が実際に調べて、使える物だけを登録します。

プログラムの知識は要りません。コマンドは全部 Claude が打ちます。

## 用意するもの

- **研究室のアカウントでログインする Windows の PC**(研究室のドメインに参加している PC)。MS-1〜MS-4 には、この PC にログインしたときの資格(Kerberos)でつなぐので、パスワードはどこにも保存しません。個人のノート PC や Mac ではできません。
- **学内のネットワーク**(MS-1〜MS-4 には学外から届きません)。
- **MS-1〜MS-4 に遠隔でコマンドを動かす許可**。まだ無ければ、準備の途中で付けます。管理者のアカウントを持っている人に、あなたのパソコンで開く窓へ管理者のアカウントとパスワードを 1 回入れてもらえば、全部の機に付きます(管理者が来られなければ、各機で打つ 2〜3 行のコマンドを Claude が表示します)。付くのは「遠隔でコマンドを動かしてよい」「リモート デスクトップで入ってよい」という許可だけで、管理者の権限は付きません。
- **Claude Code**。デスクトップアプリでもターミナル版でもかまいません(入れ方: https://code.claude.com/docs/en/quickstart )。ChatGPT を使っている人は、代わりに **Codex** でも進められます(下の「ChatGPT(Codex)を使っている人へ」)。

## ChatGPT(Codex)を使っている人へ

ブラウザやスマホの ChatGPT(会話だけの画面)では、あなたのパソコンでコマンドを動かせないので、この準備はできません。ChatGPT のアカウントでそのまま使える **Codex**(パソコンで作業する版。入れ方: https://developers.openai.com/codex/quickstart )を入れて、下の「やり方」の Claude Code を Codex に置き換えて進めてください。送る文は同じです。

- Codex は手順書の中の「Codex で進めるとき」を読んで進めます。スキルは Codex が読む場所(`~/.agents/skills/labpc/`)に書きます。
- Codex が「実行してよいか」「ネットワークを使ってよいか」と聞いてきたら、許可してください。
- Codex での通しの確認はまだしていません。うまくいかなかったら、どの手順で何が出たかを作った人に知らせてください。

## やり方

1. Claude Code を開きます。
2. 次の文をそのまま貼り付けて送ります。

   > https://github.com/tomaunno/labpc-claude-setup をこのパソコンに持ってきて、中の SETUP.md の手順どおりに、私のアカウントで研究室の MS-1〜MS-4 を使えるようにセットアップしてください。

3. あとは Claude の質問に答えるだけです。
   - 「実行してよいか」と聞かれたら「はい(Yes)」を押します。
   - MS-1〜MS-4 に、リモート デスクトップで一度ログインしてもらいます。ログインしたら、**サインアウトせずに窓の × で閉じます**(Lumerical と Zemax は、その機にあなたがログインしているときだけ動くためです)。パスワードは、開いた窓にあなたが自分で打ちます。Claude には見えません。
   - 遠隔の許可がまだ無ければ、管理者が打つコマンドが表示されます。管理者に打ってもらったら、Claude に「終わった」と伝えます。

かかる時間は 10〜20 分です(管理者の許可を待つ時間は別)。最後に小さな計算を 1 回だけ試します。機が他の人の計算で埋まっていれば、試しは割り込ませずに飛ばします。

## 終わったら

Claude に頼むだけです。

- 「この lumapi のスクリプトで半径を 20 通り振って、MS-3 で回して」
- 「MS-4 の Zemax でこのレンズのスポットを計算して」
- 「MS-3 と MS-4、いまどれくらい空いてる?」
- 「さっきのジョブはどうなった? 終わっていたら結果を取ってきて」

途中で止まっても、もう一度同じ文を送れば続きから進みます。

MS-1〜MS-4 が再起動すると、あなたのログインが消えて計算が動かなくなります。そのときは Claude が気づいて、もう一度リモート デスクトップでログインして × で閉じるよう頼みます。

## 共有の機の決まり

MS-1〜MS-4 は研究室の全員で使っています。Claude は次の決まりを自動で守ります(計算を送るたび、FDTD の計算を 1 本起動するたびに確かめます)。

- **他の人の計算から奪わない**: 他の人の計算が使っているコア(機全体の CPU の使用量から測ります)と、いつも空けておく数コアを残し、空いている分だけを使います。空きが足りなければ、送らずに止まります。
- **平日 12〜18 時は、自分の合計を機の半分まで**(コアもメモリも)。それ以外の時間は、空いている分をほぼ全部使います。
- **COMSOL は、同時に使える人数がライセンスで限られています**。誰かが COMSOL の画面を開いたままだと、その間はほかの人が計算できないことがあります。Claude は送る前に確かめ、使っている人の名前を教えて止まります。COMSOL は使い終わったら閉じてください。
- **使いっぱなしにしない**: 計算が終わったら、残ったプロセスを止め、結果を取ってきたらジョブのフォルダを消します。

## 入るもの

| 入るもの | 場所 | 役割 |
|---|---|---|
| 道具 labpc | このパソコンの `~/.labpc/`(と、ユーザーの PATH に `~/.labpc/bin`) | MS-1〜MS-4 に計算を送る・待つ・取ってくる・片付ける。共有の機の決まりを守る。使える機の一覧(`hosts.json`) |
| Claude のスキル | `~/.claude/skills/labpc/`(Codex なら `~/.agents/skills/labpc/`) | 使い方・共有の機の決まり・つまずく点と、あなたの値を Claude(か Codex)に教える |
| 確認なしで動かす許可(Claude Code で、選んだ場合だけ) | `~/.claude/settings.json` | labpc の送る・見る・待つ・取ってくるを、毎回聞かずに動かす |
| ジョブの置き場所 | MS-1〜MS-4 のあなたのホームの `labpc_jobs` | 計算のスクリプトと結果。取ってきたら消す |
| Lumerical のあなたのライセンス設定(無かったときだけ) | MS-1〜MS-4 のあなたの `%APPDATA%\Lumerical\License.ini` | 画面なしで Lumerical を起動したときに、ライセンスを聞く窓で止まらないように。Lumerical を手で使うときと同じ設定 |

準備のためだけに使った物(このセットアップのフォルダ、試しの計算のジョブ、設定ファイルの控え)は、最後に Claude が自動で片付けます。

やめるときは、`~/.labpc` とスキルのフォルダを消し、ユーザーの環境変数 PATH から `~/.labpc/bin` を外し、確認なしの許可を選んだ場合は `~/.claude/settings.json` の `labpc` で始まる許可の行を消します。MS-1〜MS-4 には、あなたのホームの `labpc_jobs`(空なら消してかまいません)と、Lumerical のライセンス設定 `License.ini`(Lumerical を手で使うときにも使う設定)が残ります。

## 管理者の方へ: 先にまとめて許可を付ける

研究室の人が準備を始める前に、管理者が自分のパソコン(研究室のドメインに参加した Windows)から、まとめて許可を付けておくこともできます。このリポジトリを手元に置き、PowerShell で次を打つと窓が開きます。管理者のアカウントとパスワードを 1 回入れると、指定した機すべてで、その人を Remote Management Users と Remote Desktop Users に足します。

```
powershell -NoProfile -ExecutionPolicy Bypass -File setup/labsetup.ps1 grant -Member <ドメイン>\<その人のアカウント> -Hosts MS-1,MS-2,MS-3,MS-4
```

ドメインの管理者のアカウントが要ります(その機だけのアカウントでは、遠隔から入れません)。遠隔実行の口が閉じている機には使えないので、その機では `Enable-PSRemoting -Force` から機ごとに打ちます。

## 開発する人向け

`SETUP.md` は AI が読む手順書で、`setup/labsetup.ps1` がその各手順の実体です(Windows の PowerShell 5.1 で動き、ほかに何も要りません)。`tool/` が入れる道具(`labpc.ps1` と、対象機に送る `remote/`、例の `examples/`)、`skill/` がスキルの雛形(`{{…}}` は `install` が埋める)、`setup/hosts.default.json` が既定の機の名前と、ライセンスサーバの既定です。機の正式な名前は、この PC のドメインから組み立てます(`MS-3` → `ms-3.<ドメイン>`)。

手で動かすこともできます。

```
powershell -NoProfile -ExecutionPolicy Bypass -File setup/labsetup.ps1 check
```

自分の環境を壊さずに試すときは、最初の `check` にだけ次のオプションを付けます。値は `setup/state.json` に残ります。

```
powershell -NoProfile -ExecutionPolicy Bypass -File setup/labsetup.ps1 check -InstallDir <仮のフォルダ>\.labpc -ClaudeDir <仮のフォルダ>\.claude -NoPath
```

手順 8 の片付けは、このフォルダごと消します。開発用の手元のコピーでは `cleanup` までにとどめ、フォルダを消すコマンドは打たないでください。

`*.ps1` は **BOM 付きの UTF-8** で保存してください(対象機と、この準備を動かす PowerShell 5.1 は、BOM の無い UTF-8 の日本語を化けて読みます)。`*.bat` は **ASCII だけ**にしてください(コマンド プロンプトは .bat を UTF-8 で読まないので、日本語のコメントでも壊れます)。MIT ライセンス。
